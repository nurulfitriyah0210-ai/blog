PEMESANAN HOTEL| MANAJEMEN KAMAR-ADMIN

1.Dashboard Admin Halaman utama yang pertama kali dilihat admin setelah masuk ke sistem. Interface ini menampilkan ringkasan informasi penting seperti jumlah kamar yang tersedia, jumlah kamar yang terdaftar, dan jumlah review tamu. Tujuannya agar admin bisa melihat kondisi hotel secara cepat tanpa harus membuka menu lain.

2. Data Kamar Interface ini menampilkan daftar seluruh kamar hotel dalam bentuk tabel. Di dalam tabel terdapat informasi seperti nama kamar, tipe kamar, harga, dan stok kamar. Admin juga dapat melakukan aksi edit atau hapus kamar melalui tombol yang tersedia.

3. Tambah Kamar Halaman ini digunakan admin untuk menambahkan kamar baru ke sistem. Admin mengisi beberapa form seperti nama kamar, tipe kamar, harga kamar, dan jumlah stok. Setelah disimpan, data kamar tersebut akan otomatis muncul pada halaman Data Kamar.

4. Edit Kamar Interface ini berfungsi untuk mengubah atau memperbarui data kamar yang sudah ada. Admin dapat memperbaiki informasi seperti nama kamar, tipe kamar, harga, atau jumlah stok kamar. Fitur ini penting agar data kamar selalu akurat.

5. Hapus Kamar Fitur ini memungkinkan admin untuk menghapus data kamar dari sistem. Biasanya digunakan jika kamar sudah tidak tersedia atau sudah tidak digunakan lagi. Dengan menghapus data tersebut, kamar tidak akan muncul lagi dalam daftar pemesanan.

6. Manajemen Tipe Kamar Interface ini digunakan untuk mengelola jenis kamar yang tersedia di hotel. Contohnya seperti Standard, Deluxe, atau Suite. Admin dapat menambah atau mengatur tipe kamar agar memudahkan pengelompokan kamar.

7. Stok Kamar Halaman ini menampilkan jumlah ketersediaan kamar yang masih kosong. Admin dapat memantau apakah kamar masih tersedia atau sudah penuh dipesan oleh tamu

8. Upload Foto Kamar Interface ini memungkinkan admin untuk mengunggah gambar kamar hotel. Foto tersebut nantinya akan ditampilkan pada halaman pemesanan agar tamu dapat melihat kondisi kamar. Tampilan foto yang menarik biasanya membuat tamu lebih tertarik untuk memesan.

9. Review Tamu Halaman ini menampilkan ulasan atau komentar dari tamu yang pernah menginap. Review tersebut berisi pengalaman tamu tentang kamar, pelayanan, maupun fasilitas hotel. Admin dapat membaca feedback tersebut sebagai bahan evaluasi pelayanan hotel

10. Balas Review Interface ini digunakan admin untuk membalas komentar atau ulasan dari tamu. Admin dapat memberikan ucapan terima kasih atau menanggapi keluhan tamu dengan sopan. Balasan yang baik dapat meningkatkan kepercayaan dan kepuasan pelanggan.
